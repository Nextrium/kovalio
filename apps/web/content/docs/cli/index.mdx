Use the CLI to deploy code, inspect releases, and manage Kovalio Cloud or a remote self-hosted installation
from any machine with Node.js and access to that API. A local Kovalio server or Docker installation is
not required for remote commands.

## Install

```bash
npm install -g kovalio
kovalio --help
```

Node.js 22 or later is required. A local `npm install kovalio` also provides the command through `npx`.
The reference follows this repository; use `--help` to check your installed version. SDK imports and
native mode are available in `kovalio` 0.8.0 and later. Newly added commands require a release containing them.

## Connect and deploy

Run `kovalio` for a guided choice of Cloud, a remote self-hosted installation, or
[installing on this machine](/docs/cli/run). To connect directly:

```bash
kovalio login \
  --api-url https://ship.example.com \
  --context production

kovalio project list
kovalio init --project proj_123
kovalio deploy --watch
```

`login` opens the token settings page and asks for a personal access token. `init` links the current
directory to a project. `deploy --watch` submits a deployment and follows its progress.
Use `kovalio login --cloud` for Kovalio Cloud. On the server that runs Kovalio, the installation
owner can use `kovalio --local project list` with automatic local authentication.

## Choose a workflow

Use `kovalio job` (alias `jobs`) to manage [scheduled jobs](/docs/guides/jobs), manual runs, and logs.

## Scripts and application code

Use `kovalio --json project list` for machine-readable command output. See [automation](/docs/cli/automation)
for CI setup and exit handling. To call the same operations directly from JavaScript or TypeScript,
use the [Node.js SDK](/docs/api/sdk).
