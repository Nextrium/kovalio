## kovalio backup policy

Backup policies (schedules) for a project

```text
kovalio backup policy [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list [options]`](/docs/cli/reference/backup/policy#kovalio-backup-policy-list) | List backup policies for a project |
| [`create [options]`](/docs/cli/reference/backup/policy#kovalio-backup-policy-create) | Create a backup policy for a project |
| [`run [options] <policyId>`](/docs/cli/reference/backup/policy#kovalio-backup-policy-run) | Trigger a policy's backup now |
| [`update <policyId> <file>`](/docs/cli/reference/backup/policy#kovalio-backup-policy-update) | Update a backup policy from a JSON file |
| [`remove\|rm <policyId>`](/docs/cli/reference/backup/policy#kovalio-backup-policy-remove) | Remove a backup policy |

## kovalio backup policy create

Create a backup policy for a project

```text
kovalio backup policy create [options]
```

| Option | Meaning |
| --- | --- |
| `--project <id>` | Project ID |
| `--destination <id>` | Backup destination ID |
| `--service <id>` | Scope the policy to a single service |
| `--cron <expr>` | Cron schedule (e.g. '0 3 * * *') |
| `--pre-deploy` | Also run this backup before each deploy |
| `--retain-count <n>` | Keep at most N runs |
| `--retain-days <n>` | Keep runs for N days |
| `--payload-kind <kind>` | Payload kind (default: auto) |
| `--payload-config <json>` | Payload config as a JSON object |
| `--pre-hook <cmd>` | Shell command run before the backup |
| `--post-hook <cmd>` | Shell command run after the backup |
| `--disabled` | Create the policy disabled |

Remove a backup policy

```text

```

## kovalio backup policy run

Trigger a policy's backup now

```text
kovalio backup policy run [options] <policyId>
```

| Argument | Meaning |
| --- | --- |
| `policyId` | Backup policy ID |

| Option | Meaning |
| --- | --- |
| `--follow` | Stream the run to completion |
