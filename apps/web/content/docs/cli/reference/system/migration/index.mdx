## kovalio system migration

Team-mode migration lifecycle

```text
kovalio system migration [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`preflight [options]`](/docs/cli/reference/system/migration#kovalio-system-migration-preflight) | Read-only readiness check for the own-server migration |
| [`start [options]`](/docs/cli/reference/system/migration#kovalio-system-migration-start) | Earlier migration endpoint; use Settings → Instance → Instance location to move |
| [`start-cloud [options]`](/docs/cli/reference/system/migration#kovalio-system-migration-start-cloud) | Migrate this instance to Kovalio Cloud |
| [`start-tunnel [options]`](/docs/cli/reference/system/migration#kovalio-system-migration-start-tunnel) | Expose this instance via an edge tunnel |
| [`switch-back [options]`](/docs/cli/reference/system/migration#kovalio-system-migration-switch-back) | Reverse migration back to single-user (teammates lose access) |

## kovalio system migration preflight

Read-only readiness check for the own-server migration

```text
kovalio system migration preflight [options]
```

| Option | Meaning |
| --- | --- |
| `--server-id <id>` | Target server id |
| `--hostname <host>` | Custom domain pointing at the server |
| `--slug <slug>` | Free &lt;slug&gt;.opsh.io subdomain |

## kovalio system migration start

kovalio system migration start [options]

## kovalio system migration start-cloud

Migrate this instance to Kovalio Cloud

```text
kovalio system migration start-cloud [options]
```

| Option | Meaning |
| --- | --- |
| `--allow-non-empty-target` | Proceed even if the cloud org already has projects |

| --- | --- |

## kovalio system migration switch-back

Reverse migration back to single-user (teammates lose access)

```text
kovalio system migration switch-back [options]
```

| Option | Meaning |
| --- | --- |
| `--abandon-remote` | Skip pulling remote data; keep the local DB as-is |
| `-y, --yes` | Skip the confirmation prompt |
