## kovalio system

Instance settings, onboarding, migration, and data transfer

```text
kovalio system [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`settings`](/docs/cli/reference/system/settings#kovalio-system-settings) | Read or update instance settings |
| [`onboarding`](/docs/cli/reference/system/onboarding#kovalio-system-onboarding) | First-run instance setup |
| [`upgrade-to-auth [options]`](/docs/cli/reference/system#kovalio-system-upgrade-to-auth) | Promote a zero-auth instance to email/password login |
| [`browse [path]`](/docs/cli/reference/system#kovalio-system-browse) | List directories on the instance host (defaults to home) |
| [`migration`](/docs/cli/reference/system/migration#kovalio-system-migration) | Team-mode migration lifecycle |
| [`data-transfer`](/docs/cli/reference/system#kovalio-system-data-transfer) | Instance and project data export / import (instance-admin only) |
| [`info`](/docs/cli/reference/system#kovalio-system-info) | Read product mode, version and advertised capabilities |
| [`notices`](/docs/cli/reference/system#kovalio-system-notices) | Read advisories for this instance and workspace |
| [`email`](/docs/cli/reference/system#kovalio-system-email) | Manage the instance's invitation and authentication email transport |
| [`untracked-sites`](/docs/cli/reference/system#kovalio-system-untracked-sites) | Inspect edge sites not tracked by Kovalio |

## kovalio system data-transfer

Instance and project data export / import (instance-admin only)

```text
kovalio system data-transfer [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`preview [options] [file]`](/docs/cli/reference/system#kovalio-system-data-transfer-preview) | Review export row counts, scope, projects and credentials before exporting |
| [`export [options]`](/docs/cli/reference/system#kovalio-system-data-transfer-export) | Export instance or project data, including plaintext credentials, to a private JSON file |
| [`import [options]`](/docs/cli/reference/system#kovalio-system-data-transfer-import) | Import an instance export file |

## kovalio system data-transfer export

Export instance or project data, including plaintext credentials, to a private JSON file

```text
kovalio system data-transfer export [options]
```

| Option | Meaning |
| --- | --- |
| `--selection <file>` | Export selection as JSON, or - for stdin |
| `--out <file>` | Write the export to this file instead of stdout |

## kovalio system data-transfer import

Import an instance export file

```text
kovalio system data-transfer import [options]
```

| Option | Meaning |
| --- | --- |
| `--file <path>` | Path to an export file |
| `--passphrase <passphrase>` | Passphrase for a legacy encrypted export |
| `--passphrase-file <file>` | Legacy passphrase file, or - for stdin |
| `--selection <file>` | Import selection and reviewed server mappings as JSON |
| `--mode <mode>` | wipe (replace) \| merge (choices: "wipe", "merge", default: "wipe") |
| `-y, --yes` | Skip the confirmation prompt |

## kovalio system upgrade-to-auth

Promote a zero-auth instance to email/password login

```text
kovalio system upgrade-to-auth [options]
```

| Option | Meaning |
| --- | --- |
| `--name <name>` | Account display name |
| `--email <email>` | Account email |
| `--password <password>` | Account password (prompted if omitted) |
| `--use-own-mail-server` | Warm the self-hosted mail server for auth emails |
