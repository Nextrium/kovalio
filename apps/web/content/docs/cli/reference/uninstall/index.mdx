## kovalio uninstall

Remove Kovalio from this machine: stop it, delete its data (database, certs, edge config), its images, and ~/.kovalio. Deployed apps are left running.

```text
kovalio uninstall [options]
```

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Skip the confirmation prompt (for scripts) |
| `--keep-data` | Keep the database/certs volumes and ~/.kovalio — remove only the running stack |
| `--keep-images` | Don't delete the Kovalio container images |
