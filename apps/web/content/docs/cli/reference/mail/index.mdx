## kovalio mail

```text
kovalio mail [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`steps`](/docs/cli/reference/mail#kovalio-mail-steps) | List the mail setup steps |

| [`servers`](/docs/cli/reference/mail#kovalio-mail-servers) | List every server the mail stack is installed on |
| [`scan <serverId>`](/docs/cli/reference/mail#kovalio-mail-scan) | Probe a server for an existing mail install (read-only) |
| [`adopt <serverId>`](/docs/cli/reference/mail#kovalio-mail-adopt) | Re-adopt an existing mail install whose orchestrator state was lost |
| [`setup [options] <serverId>`](/docs/cli/reference/mail#kovalio-mail-setup) | Start or resume the mail setup wizard (streams over SSE) |
| [`cancel`](/docs/cli/reference/mail#kovalio-mail-cancel) | Cancel the mail setup currently running |
| [`dns-ack <serverId>`](/docs/cli/reference/mail#kovalio-mail-dns-ack) | Acknowledge that DNS records are published (releases the DKIM gate) |
| [`ptr-ack <serverId>`](/docs/cli/reference/mail#kovalio-mail-ptr-ack) | Acknowledge that reverse DNS (PTR) is configured |
| [`reset [options] <serverId>`](/docs/cli/reference/mail#kovalio-mail-reset) | Wipe the on-server setup state file (does NOT touch installed daemons) |
| [`forget <serverId>`](/docs/cli/reference/mail#kovalio-mail-forget) | Stop managing a mail server (drops the DB row; leaves the stack + state intact) |
| [`health [options] <serverId>`](/docs/cli/reference/mail#kovalio-mail-health) | Show live status of every mail daemon, and whether mail is leaving the box |
| [`logs [options] <serverId> <component>`](/docs/cli/reference/mail#kovalio-mail-logs) | Tail a mail component's journal (snapshot) |
| [`postmaster`](/docs/cli/reference/mail#kovalio-mail-postmaster) | Manage the postmaster mailbox |
| [`build [options]`](/docs/cli/reference/mail#kovalio-mail-build) | Build the kovalio-mail engine image locally from a source checkout [dev] |
| [`domain`](/docs/cli/reference/mail/domain#kovalio-mail-domain) | Manage mail domains, their dependencies and DNS |
| [`mailbox`](/docs/cli/reference/mail/mailbox#kovalio-mail-mailbox) | Manage mailbox accounts and storage limits |
| [`alias`](/docs/cli/reference/mail/alias#kovalio-mail-alias) | Manage forwards and catch-all addresses |
| [`certificate`](/docs/cli/reference/mail#kovalio-mail-certificate) | Inspect and renew mail TLS through Kovalio's shared edge |
| [`relay`](/docs/cli/reference/mail#kovalio-mail-relay) | Manage outbound SMTP delivery without exposing stored passwords |
| [`backup`](/docs/cli/reference/mail#kovalio-mail-backup) | Manage mail backup policy; use kovalio backup for runs and restores |
| [`inbound`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound) | Manage inbound-mail notification rules |
| [`stats <server>`](/docs/cli/reference/mail#kovalio-mail-stats) | Read domain, account and storage totals |
| [`dns-scan [options] <server>`](/docs/cli/reference/mail#kovalio-mail-dns-scan) | Inspect mail DNS without changing records |
| [`test-email [options] <server>`](/docs/cli/reference/mail#kovalio-mail-test-email) | Send one delivery test to the specified recipient |
| [`rotate-platform-mailbox [options] <server>`](/docs/cli/reference/mail#kovalio-mail-rotate-platform-mailbox) | Rotate Kovalio's private delivery credential; never prints its password |
| [`component [options] <server> <key> <action>`](/docs/cli/reference/mail#kovalio-mail-component) | Control a managed mail component; inspect health to confirm recovery |
| [`restart-all [options] <server>`](/docs/cli/reference/mail#kovalio-mail-restart-all) | Restart managed mail components; delivery may be briefly interrupted |
| [`webmail`](/docs/cli/reference/mail#kovalio-mail-webmail) | Deploy webmail through the normal app deployment workflow |

## kovalio mail setup

```text
kovalio mail setup [options] <serverId>
```

| Argument | Meaning |
| --- | --- |
| `serverId` | Server ID to install the mail stack on |

| Option | Meaning |
| --- | --- |
| `-d, --domain <domain>` | Mail domain (e.g. example.com) |

| `--config <json>` | iRedMail config overrides as a JSON object |
| `--config-file <file>` | Setup config file, or - for stdin (recommended for passwords) |
