## kovalio mail inbound

Manage inbound-mail notification rules

```text
kovalio mail inbound [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list <server>`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound-list) | List rules and paused state |
| [`create [options] <id> [file]`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound-create) | Create a rule for existing notification channels |
| [`update [options] <parent> <id> [file]`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound-update) | Update a rule; pausedReason=null explicitly clears its pause |
| [`remove [options] <server> <rule>`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound-remove) | Remove a rule and release unneeded capture |
| [`test <server>`](/docs/cli/reference/mail/inbound#kovalio-mail-inbound-test) | Preview matches without sending notifications or deleting captured mail |

## kovalio mail inbound create

Create a rule for existing notification channels

```text
kovalio mail inbound create [options] <id> [file]
```

| Argument | Meaning |
| --- | --- |
| `id` | Resource ID |
| `file` | JSON input file, or - for stdin |

| Option | Meaning |
| --- | --- |
| `--schema` | Print the accepted JSON schema without making a request |

## kovalio mail inbound list

List rules and paused state

```text
kovalio mail inbound list [options] <server>
```

## kovalio mail inbound remove

Remove a rule and release unneeded capture

```text
kovalio mail inbound remove [options] <server> <rule>
```

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Confirm removal |

## kovalio mail inbound test

Preview matches without sending notifications or deleting captured mail

```text
kovalio mail inbound test [options] <server>
```

## kovalio mail inbound update

Update a rule; pausedReason=null explicitly clears its pause

```text
kovalio mail inbound update [options] <parent> <id> [file]
```

| Argument | Meaning |
| --- | --- |
| `parent` | Parent resource ID |
| `id` | Resource ID or name |
| `file` | JSON input file, or - for stdin |

| Option | Meaning |
| --- | --- |
| `--schema` | Print the accepted JSON schema without making a request |
