## kovalio project database

Manage project databases, replicas, backups and application connections

```text
kovalio project database [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list <project>`](/docs/cli/reference/project/database#kovalio-project-database-list) | List project databases and their operation sequences |
| [`imports <project>`](/docs/cli/reference/project/database#kovalio-project-database-imports) | List backup artifacts available to import into a database |
| [`get [options] <project> <database>`](/docs/cli/reference/project/database#kovalio-project-database-get) | Read database health, backups and progress |
| [`create [options] <id> [file]`](/docs/cli/reference/project/database#kovalio-project-database-create) | Provision a database, optionally from an import, copy or backup |
| [`update [options] <id> [file]`](/docs/cli/reference/project/database#kovalio-project-database-update) | Apply database configuration at the reviewed sequence |
| [`retry [options] <project> <database>`](/docs/cli/reference/project/database#kovalio-project-database-retry) | Resume a failed database operation at its current sequence |
| [`backup [options] <project> <database>`](/docs/cli/reference/project/database#kovalio-project-database-backup) | Start a database backup at the reviewed sequence |
| [`connect [options] <id> [file]`](/docs/cli/reference/project/database#kovalio-project-database-connect) | Bind a database to an environment key; null disconnects, replacement needs its sequence |
| [`remove [options] <id> [file]`](/docs/cli/reference/project/database#kovalio-project-database-remove) | Remove a named database with an explicit retain-or-delete-data decision |
| [`events [options] <project>`](/docs/cli/reference/project/database#kovalio-project-database-events) | Stream health and operation progress |

## kovalio project database backup

Start a database backup at the reviewed sequence

```text
kovalio project database backup [options] <project> <database>
```

| Argument | Meaning |
| --- | --- |
| `project` | Project ID |
| `database` | Database ID |

| Option | Meaning |
| --- | --- |
| `--sequence <number>` | Current database sequence |

## kovalio project database connect

Bind a database to an environment key; null disconnects, replacement needs its sequence

```text

```

| Argument | Meaning |
| --- | --- |
| `id` | Resource ID |
| `file` | JSON input file, or - for stdin |

| Option | Meaning |
| --- | --- |
| `--schema` | Print the accepted JSON schema without making a request |
