Use `kovalio <command> --help` to check the version installed on your machine. `<value>` is required; `[value]` is optional. Aliases appear beside the command name.

## Global options

| Option | Meaning |
| --- | --- |
| `-V, --version` | output the version number |
| `--json` | Machine-readable JSON output (stdout data only) |
| `--context <name>` | Use a saved connection for this command without changing the default |
| `--api-url <url>` | Use a remote API for this command; authenticate with KOVALIO_TOKEN |
| `--local` | Use this machine's installation with its private administrator credential |
| `--organization <id>` | Use a fixed organization scope for SDK resource commands (remote only) |
| `--native-config <file>` | Run SDK commands using an explicitly trusted JavaScript configuration |
| `-h, --help` | display help for command |

Put global options before the command, for example `kovalio --json project list`. See [native mode](/docs/cli/native) before using `--native-config`.

## Local installation

| Command | Purpose |
| --- | --- |
| [`kovalio up`](/docs/cli/reference/up) | Start Kovalio as a persistent service (boot + auto-restart); --foreground to run attached |
| [`kovalio stop`](/docs/cli/reference/stop) | Stop Kovalio (started by `kovalio up`) — it won't restart or return on reboot |
| [`kovalio status`](/docs/cli/reference/status) | Show the local Kovalio service (installed/running, ports) and the active context's API health |
| [`kovalio doctor`](/docs/cli/reference/doctor) | Check database + services health and repair a corrupt local database |
| [`kovalio open`](/docs/cli/reference/open) | Open the Kovalio dashboard in your browser |
| [`kovalio install`](/docs/cli/reference/install) | Download and install the Kovalio desktop app for this OS |
| [`kovalio update`](/docs/cli/reference/update) | Update the Kovalio CLI + bundled server to the latest release |
| [`kovalio uninstall`](/docs/cli/reference/uninstall) | Remove Kovalio from this machine: stop it, delete its data (database, certs, edge config), its images, and ~/.kovalio. Deployed apps are left running. |
| [`kovalio reset-admin-password`](/docs/cli/reference/reset-admin-password) | Reset the local admin login on THIS machine (no sign-in required) |
