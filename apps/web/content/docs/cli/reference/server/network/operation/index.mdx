## kovalio server network operation

Review and execute an exact managed-network plan

```text
kovalio server network operation [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`plan [options] [file]`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-plan) | Plan managed-network configuration or removal with an idempotent request ID |
| [`get <id>`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-get) | Read a plan, its hash and execution progress |
| [`apply [options] <id>`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-apply) | Apply, resume or roll back a reviewed plan without rebuilding it |
| [`discard [options] [file]`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-discard) | Discard a plan using its exact hash |
| [`remove-member [options] [file]`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-remove-member) | Remove a host using the operation's exact plan hash and sequence |
| [`events [options] <id>`](/docs/cli/reference/server/network/operation#kovalio-server-network-operation-events) | Stream plan execution and recovery progress |

## kovalio server network operation apply

Apply, resume or roll back a reviewed plan without rebuilding it

```text
kovalio server network operation apply [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Operation ID |

| Option | Meaning |
| --- | --- |
| `--plan-hash <hash>` | Exact hash of the plan you reviewed |
| `--action <action>` | Execution action (choices: "apply", "resume", "rollback", default: "apply") |
| `-y, --yes` | Confirm this plan's host changes |
