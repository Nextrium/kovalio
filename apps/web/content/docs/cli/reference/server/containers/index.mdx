## kovalio server containers

Inspect and update infrastructure containers through the engine

```text
kovalio server containers [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list`](/docs/cli/reference/server/containers#kovalio-server-containers-list) | List edge and mail containers across servers |
| [`scan`](/docs/cli/reference/server/containers#kovalio-server-containers-scan) | Refresh infrastructure container state |
| [`behind`](/docs/cli/reference/server/containers#kovalio-server-containers-behind) | Count outdated infrastructure containers |
| [`issues`](/docs/cli/reference/server/containers#kovalio-server-containers-issues) | Show missing or stopped infrastructure containers |
| [`active`](/docs/cli/reference/server/containers#kovalio-server-containers-active) | Show running and recently completed container updates |
| [`get <server>`](/docs/cli/reference/server/containers#kovalio-server-containers-get) | Read a server's infrastructure containers |
| [`scan-server <server>`](/docs/cli/reference/server/containers#kovalio-server-containers-scan-server) | Refresh a server's infrastructure containers |
| [`session <server> <component>`](/docs/cli/reference/server/containers#kovalio-server-containers-session) | Find an in-progress update before retrying |
| [`events [options] <server> <component>`](/docs/cli/reference/server/containers#kovalio-server-containers-events) | Reattach to update progress without starting another update |
| [`apply [options] <server> <component>`](/docs/cli/reference/server/containers#kovalio-server-containers-apply) | Apply an infrastructure update and follow its existing engine session |
| [`apply-all [options]`](/docs/cli/reference/server/containers#kovalio-server-containers-apply-all) | Queue eligible infrastructure updates; use active to inspect completion |

## kovalio server containers active

Show running and recently completed container updates

```text
kovalio server containers active [options]
```

## kovalio server containers apply

Apply an infrastructure update and follow its existing engine session

```text
kovalio server containers apply [options] <server> <component>
```

| Argument | Meaning |
| --- | --- |
| `server` | Server ID |
| `component` | edge \| mail |

| Option | Meaning |
| --- | --- |
| `--intent <intent>` | Operation to apply (choices: "update", "repair", default: "update") |
| `--timeout <ms>` | Stop following after this deadline |
| `-y, --yes` | Confirm the container restart |

## kovalio server containers apply-all

Queue eligible infrastructure updates; use active to inspect completion

```text
kovalio server containers apply-all [options]
```

| Option | Meaning |
| --- | --- |
| `--intent <intent>` | Limit queued work to this intent (choices: "update", "repair") |
| `-y, --yes` | Confirm restarts across eligible servers |
