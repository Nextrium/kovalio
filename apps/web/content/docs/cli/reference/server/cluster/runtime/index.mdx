## kovalio server cluster runtime

Install or recover the shared scaling runtime

```text
kovalio server cluster runtime [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`get <id>`](/docs/cli/reference/server/cluster/runtime#kovalio-server-cluster-runtime-get) | Read runtime status and sequence |
| [`setup [options] [file]`](/docs/cli/reference/server/cluster/runtime#kovalio-server-cluster-runtime-setup) | Install the runtime using a reviewed cluster revision and request ID |
| [`retry [options] <id>`](/docs/cli/reference/server/cluster/runtime#kovalio-server-cluster-runtime-retry) | retry the runtime at the reviewed sequence |
| [`remove [options] <id>`](/docs/cli/reference/server/cluster/runtime#kovalio-server-cluster-runtime-remove) | remove the runtime at the reviewed sequence |
| [`events [options] <id>`](/docs/cli/reference/server/cluster/runtime#kovalio-server-cluster-runtime-events) | Stream runtime progress |

## kovalio server cluster runtime events

Stream runtime progress

```text
kovalio server cluster runtime events [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Compute cluster ID |

| Option | Meaning |
| --- | --- |
| `--timeout <ms>` | Stop after this deadline |

## kovalio server cluster runtime remove

remove the runtime at the reviewed sequence

```text

```

| Argument | Meaning |
| --- | --- |
| `id` | Compute cluster ID |

| Option | Meaning |
| --- | --- |
| `--sequence <number>` | Current sequence from runtime get |
| `-y, --yes` | Confirm host changes |
