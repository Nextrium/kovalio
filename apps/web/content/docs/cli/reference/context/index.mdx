## kovalio context

Manage connection contexts (list/use/add/rm)

```text
kovalio context|ctx [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list\|ls`](/docs/cli/reference/context#kovalio-context-list) | List configured contexts |
| [`use <name>`](/docs/cli/reference/context#kovalio-context-use) | Switch the active context |
| [`add [options] <name>`](/docs/cli/reference/context#kovalio-context-add) | Create or update a context's endpoints/token |
| [`rm\|remove <name>`](/docs/cli/reference/context#kovalio-context-rm) | Remove a context (cannot remove the active one) |

## kovalio context add

Create or update a context's endpoints/token

```text
kovalio context add [options] <name>
```

| Argument | Meaning |
| --- | --- |
| `name` | Context name |

| Option | Meaning |
| --- | --- |
| `--api-url <url>` | API base URL |
| `--dashboard-url <url>` | Dashboard base URL |
| `--token <token>` | Personal Access Token to store |
| `--organization <id>` | Pin this context to a Cloud or self-hosted organization |
| `--use` | Switch to this context after adding |
