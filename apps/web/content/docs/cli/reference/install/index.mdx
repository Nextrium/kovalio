## kovalio install

Download and install the Kovalio desktop app for this OS

```text
kovalio install [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`cache`](/docs/cli/reference/install#kovalio-install-cache) | Manage the local download cache (list/verify/clean/path) |

| Option | Meaning |
| --- | --- |
| `--version <tag>` | Release tag to install (e.g. v1.2.3) |
| `--latest` | Install the latest release (default) |
| `--force` | Re-download even if a verified copy is cached |
| `--no-verify` | Skip SHA-256 verification (allowed when no sidecar exists) |
| `--no-launch` | Install without launching the app |

## kovalio install cache

Manage the local download cache (list/verify/clean/path)

```text
kovalio install cache [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`path`](/docs/cli/reference/install#kovalio-install-cache-path) | Print the cache directory path |
| [`list\|ls`](/docs/cli/reference/install#kovalio-install-cache-list) | List cached release assets |
| [`verify [tag]`](/docs/cli/reference/install#kovalio-install-cache-verify) | Re-hash cached assets and compare to their .sha256 sidecar |
| [`clean [tag]`](/docs/cli/reference/install#kovalio-install-cache-clean) | Delete cached release assets |

## kovalio install cache clean

Delete cached release assets

```text
kovalio install cache clean [options] [tag]
```

| Argument | Meaning |
| --- | --- |
| `tag` | Only remove this release tag (default: all) |

## kovalio install cache list

List cached release assets

```text
kovalio install cache list|ls [options]
```

## kovalio install cache path

Print the cache directory path

```text
kovalio install cache path [options]
```

## kovalio install cache verify

Re-hash cached assets and compare to their .sha256 sidecar

```text
kovalio install cache verify [options] [tag]
```

| Argument | Meaning |
| --- | --- |
| `tag` | Only verify assets under this release tag |
