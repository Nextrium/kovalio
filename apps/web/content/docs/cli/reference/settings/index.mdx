## kovalio settings

Manage user preferences on the selected Kovalio instance

```text
kovalio settings [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`get`](/docs/cli/reference/settings#kovalio-settings-get) | Read deployment, cloning and transfer preferences |
| [`update <file>`](/docs/cli/reference/settings#kovalio-settings-update) | Update supported user preferences |
| [`build-mode <value>`](/docs/cli/reference/settings#kovalio-settings-build-mode) | Set the default build-mode |
| [`route-strategy <value>`](/docs/cli/reference/settings#kovalio-settings-route-strategy) | Set the default route-strategy |
| [`clone-strategy <value>`](/docs/cli/reference/settings#kovalio-settings-clone-strategy) | Set the default clone-strategy |
| [`deploy-defaults <file>`](/docs/cli/reference/settings#kovalio-settings-deploy-defaults) | Set deployment destination defaults |
| [`clone-token [options] <file>`](/docs/cli/reference/settings#kovalio-settings-clone-token) | Save a cloning credential; responses do not disclose the token |
| [`clear-clone-token`](/docs/cli/reference/settings#kovalio-settings-clear-clone-token) | Remove the saved cloning credential |
| [`transfer [options]`](/docs/cli/reference/settings#kovalio-settings-transfer) | Set volume transfer preferences |
| [`git-forwarding <state>`](/docs/cli/reference/settings#kovalio-settings-git-forwarding) | Control forwarding of git identity to build servers |
| [`appearance`](/docs/cli/reference/settings#kovalio-settings-appearance) | Manage personal theme JSON on the selected instance |

## kovalio settings appearance

Manage personal theme JSON on the selected instance

```text
kovalio settings appearance [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`get`](/docs/cli/reference/settings#kovalio-settings-appearance-get) | Export saved appearance JSON |
| [`set <file>`](/docs/cli/reference/settings#kovalio-settings-appearance-set) | Import and save a personal theme library |
| [`reset`](/docs/cli/reference/settings#kovalio-settings-appearance-reset) | Clear saved personal appearance |

## kovalio settings appearance get

Export saved appearance JSON

```text
kovalio settings appearance get [options]
```

## kovalio settings appearance reset

Clear saved personal appearance

```text
kovalio settings appearance reset [options]
```

## kovalio settings appearance set

Import and save a personal theme library

```text
kovalio settings appearance set [options] <file>
```

| Argument | Meaning |
| --- | --- |
| `file` | Appearance JSON file, or - for stdin |

```text

```

| Argument | Meaning |
| --- | --- |
| `value` | auto \| server \| local |

## kovalio settings clone-strategy

Set the default clone-strategy

```text
kovalio settings clone-strategy [options] <value>
```

| Argument | Meaning |
| --- | --- |
| `value` | prompt \| local \| remote-with-token |

## kovalio settings clone-token

Save a cloning credential; responses do not disclose the token

```text
kovalio settings clone-token [options] <file>
```

| Argument | Meaning |
| --- | --- |
| `file` | Token file, or - for stdin |

| Option | Meaning |
| --- | --- |
| `--default` | Use this token by default for cloning |

## kovalio settings deploy-defaults


| Argument | Meaning |
| --- | --- |
| `file` | JSON defaultDeployTarget and defaultServerId; null clears, - reads stdin |

## kovalio settings transfer

Set volume transfer preferences

```text
kovalio settings transfer [options]
```

| Option | Meaning |
| --- | --- |
| `--mode <mode>` | Transfer method (choices: "auto", "stream", "direct", "rsync") |
| `--compression <format>` | Compression (choices: "auto", "zstd", "gzip", "none") |

## kovalio settings update

Update supported user preferences

```text
kovalio settings update [options] <file>
```

| Argument | Meaning |
| --- | --- |
| `file` | JSON settings patch, or - for stdin |
