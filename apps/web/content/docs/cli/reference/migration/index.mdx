## kovalio migration

Discover, import, move and copy Docker workloads between authorized servers, including Cloud

```text
kovalio migration [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`source`](/docs/cli/reference/migration#kovalio-migration-source) | Manage migration-only SSH sources; these cannot run general server commands |
| [`scan [options] <server>`](/docs/cli/reference/migration#kovalio-migration-scan) | Read Docker services, container IDs, routes and volumes with environment values masked |
| [`repo-compose [options] [file]`](/docs/cli/reference/migration#kovalio-migration-repo-compose) | Read repository Compose services with environment values masked |
| [`preview [options] [file]`](/docs/cli/reference/migration#kovalio-migration-preview) | Inspect transfer size, blocked services, conflicts and downtime before moving |
| [`adopt [options] [file]`](/docs/cli/reference/migration#kovalio-migration-adopt) | Register discovered services in place on a self-hosted controller |
| [`reimport [options] [file]`](/docs/cli/reference/migration#kovalio-migration-reimport) | Recover a scanned orphaned Kovalio project with its original ID |
| [`start [options] [file]`](/docs/cli/reference/migration#kovalio-migration-start) | Start the reviewed Docker migration; keep killOriginals false to review cutover |
| [`project [options] [file]`](/docs/cli/reference/migration#kovalio-migration-project) | Move or copy an existing project; the run waits for explicit cutover |
| [`reveal-env [options] [file]`](/docs/cli/reference/migration#kovalio-migration-reveal-env) | Print only the requested environment keys from one source container (secrets) |
| [`get <id>`](/docs/cli/reference/migration#kovalio-migration-get) | Read durable state, logs, transfer progress, pending prompts and cutover token |
| [`active <server>`](/docs/cli/reference/migration#kovalio-migration-active) | Find an active run before starting or reattaching to work |
| [`list [options]`](/docs/cli/reference/migration#kovalio-migration-list) | List up to 50 runs for a server or project |
| [`events <id>`](/docs/cli/reference/migration#kovalio-migration-events) | Reattach to a migration's progress without restarting it |
| [`respond [options] <id>`](/docs/cli/reference/migration#kovalio-migration-respond) | Respond to the exact pending decision returned by migration get |
| [`resume [options] <id> [file]`](/docs/cli/reference/migration#kovalio-migration-resume) | Resume a partial run with reviewed path overrides or skips |
| [`cutover [options] <id>`](/docs/cli/reference/migration#kovalio-migration-cutover) | Confirm the reviewed target; never invents a cutover token or changes the retirement choice |
| [`cancel [options] <id>`](/docs/cli/reference/migration#kovalio-migration-cancel) | Request cancellation and rollback; poll migration get until it finishes |
| [`cleanup-target [options] <id>`](/docs/cli/reference/migration#kovalio-migration-cleanup-target) | Delete target volumes copied by a failed migration; source data remains |
| [`remove [options] <id>`](/docs/cli/reference/migration#kovalio-migration-remove) | Delete a terminal run's history record; retain the migrated project and data |

## kovalio migration active

Find an active run before starting or reattaching to work

```text

```

## kovalio migration cutover

Confirm the reviewed target; never invents a cutover token or changes the retirement choice

```text
kovalio migration cutover [options] <id>
```

| Option | Meaning |
| --- | --- |
| `--token-file <file>` | This run's confirmation token, or - for stdin |
| `--originals <choice>` | Retain source containers or authorize their destruction (choices: "retain", "retire") |
| `-y, --yes` | Confirm cutover |
