## kovalio init

Link the current directory to an Kovalio project (.kovalio/project.json)

```text
kovalio init [options]
```

| Option | Meaning |
| --- | --- |
| `--project <id>` | Project id to link (skips the picker) |
| `--environment <name>` | Default deploy variable set: production \| preview (default: "production") |
| `--dir <path>` | Directory to initialize (default: ".") |
| `--force` | Overwrite an existing project link |
| `-y, --yes` | Non-interactive: fail instead of prompting |
