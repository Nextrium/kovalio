## kovalio credential

Manage stored registry and DNS credentials; reads return masked secrets

```text
kovalio credential|credentials [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`providers`](/docs/cli/reference/credential#kovalio-credential-providers) | Show supported providers and their required fields |
| [`list\|ls`](/docs/cli/reference/credential#kovalio-credential-list) | List stored credentials |
| [`get <id>`](/docs/cli/reference/credential#kovalio-credential-get) | Show one credential with secrets masked |
| [`create <file>`](/docs/cli/reference/credential#kovalio-credential-create) | Create a credential; required provider fields are validated by the engine |
| [`update <id> <file>`](/docs/cli/reference/credential#kovalio-credential-update) | Update selected credential fields without echoing secrets |
| [`verify <id>`](/docs/cli/reference/credential#kovalio-credential-verify) | Verify a credential against its provider |
| [`remove\|rm [options] <id>`](/docs/cli/reference/credential#kovalio-credential-remove) | Remove a stored credential |

## kovalio credential create

Create a credential; required provider fields are validated by the engine

```text
kovalio credential create [options] <file>
```

| Argument | Meaning |
| --- | --- |
| `file` | JSON object with provider, name, optional selector and values |

## kovalio credential get

Show one credential with secrets masked

```text
kovalio credential get [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |

## kovalio credential list

List stored credentials

## kovalio credential providers

Show supported providers and their required fields

```text

```

## kovalio credential remove

Remove a stored credential

```text
kovalio credential remove|rm [options] <id>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |

| Option | Meaning |
| --- | --- |
| `-y, --yes` | Skip confirmation |

## kovalio credential update

Update selected credential fields without echoing secrets

```text
kovalio credential update [options] <id> <file>
```

| Argument | Meaning |
| --- | --- |
| `id` | Credential ID |
| `file` | JSON credential patch |
