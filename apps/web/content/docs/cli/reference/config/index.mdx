## kovalio config

Author and validate kovalio.json (declarative deploy config)

```text
kovalio config [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`init [options]`](/docs/cli/reference/config#kovalio-config-init) | Scaffold an kovalio.json in the current directory |
| [`validate [file]`](/docs/cli/reference/config#kovalio-config-validate) | Validate an kovalio.json against the deploy schema |

## kovalio config init

Scaffold an kovalio.json in the current directory

```text
kovalio config init [options]
```

| Option | Meaning |
| --- | --- |
| `--dir <path>` | Directory to write into (default: ".") |
| `--force` | Overwrite an existing kovalio.json |

## kovalio config validate

Validate an kovalio.json against the deploy schema

```text
kovalio config validate [options] [file]
```

| Argument | Meaning |
| --- | --- |
| `file` | Path to the config file (default: "kovalio.json") |
