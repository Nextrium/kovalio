## kovalio access invitations

Manage workspace invitations

```text
kovalio access invitations [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`list`](/docs/cli/reference/access/invitations#kovalio-access-invitations-list) | List pending invitations |
| [`create <file>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-create) | Invite a member with optional resource grants |
| [`accept <id>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-accept) | accept a workspace invitation |
| [`reject <id>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-reject) | reject a workspace invitation |
| [`cancel <id>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-cancel) | cancel a workspace invitation |
| [`resend [options] <id>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-resend) | Resend an existing invitation |
| [`materialize <id>`](/docs/cli/reference/access/invitations#kovalio-access-invitations-materialize) | Recover resource grants from an already-accepted invitation |
