## kovalio open

Open the Kovalio dashboard in your browser

```text
kovalio open [options]
```

| Option | Meaning |
| --- | --- |
| `--cloud` | Open the hosted cloud dashboard (kovalio.nextrium.org) |
| `--dashboard-url <url>` | Dashboard base URL to open |
| `--context <name>` | Context whose dashboard URL to open |
| `--path <path>` | Path to open on the dashboard (e.g. /settings) |
