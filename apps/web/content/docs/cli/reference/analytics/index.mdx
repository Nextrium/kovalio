## kovalio analytics

Read project traffic, deployments and runtime resource measurements

```text
kovalio analytics [options] [command]
```

| Subcommand | Purpose |
| --- | --- |
| [`dashboard`](/docs/cli/reference/analytics#kovalio-analytics-dashboard) | Show totals for accessible projects and deployments |
| [`summary [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-summary) | Show request, visitor and bandwidth totals |
| [`traffic [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-traffic) | Show traffic totals and time buckets |
| [`periods [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-periods) | Read traffic time buckets |
| [`geo [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-geo) | Read traffic geography and request paths |
| [`deployments <project>`](/docs/cli/reference/analytics#kovalio-analytics-deployments) | Show deployment reliability and build duration |
| [`usage <project>`](/docs/cli/reference/analytics#kovalio-analytics-usage) | Read current project runtime usage |
| [`container <project>`](/docs/cli/reference/analytics#kovalio-analytics-container) | Read runtime container details |
| [`resources <project>`](/docs/cli/reference/analytics#kovalio-analytics-resources) | Read service measurements and destination capacity |
| [`history [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-history) | Read historical CPU, memory and network usage |
| [`paths <project> <state>`](/docs/cli/reference/analytics#kovalio-analytics-paths) | Enable or disable collection of request paths |
| [`watch [options] <project>`](/docs/cli/reference/analytics#kovalio-analytics-watch) | Stream live project resource measurements |
| [`server`](/docs/cli/reference/analytics#kovalio-analytics-server) | Inspect traffic for a domain handled by a particular server |
