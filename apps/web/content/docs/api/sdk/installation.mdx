Requires **Node.js 22 or later**. ESM, CommonJS, and TypeScript declarations are included.

## Install from npm

The `kovalio` package includes Ship SDK and the CLI starting with **0.8.0**:

```bash
npm install kovalio
```

If your project has an older CLI-only version, upgrade the local dependency:

```bash
npm install kovalio@latest
npm ls kovalio
```

Versions before 0.8.0 do not include the SDK entry points. Upgrading the package does not upgrade
a remote Kovalio server; see [server compatibility](/docs/api/sdk/compatibility#fixed-organization-scopes).

## Test changes from source

Contributors can build and install a local package without publishing it:

1. Build the public package from the repository root:

   ```bash
   bun install --frozen-lockfile
   bun run build:sdk
   ```

2. Create a tarball. Use the filename printed by `npm pack`:

   ```bash
   cd packages/kovalio
   npm pack
   ```

3. Install that tarball in your Node project:

   ```bash
   npm install /absolute/path/to/kovalio-0.8.0.tgz
   ```

Use the actual tarball filename printed by `npm pack`; it follows the checkout's package version.

## Choose an import

| Import | Provides |
| --- | --- |
| `kovalio` | Native factory, remote clients, deployment helpers, public types, and errors. |
| `kovalio/client` | Remote clients and HTTP helpers. |
| `kovalio/native` | Native factory, identity types, lifecycle options, and scoped operations. |

<Tabs items={['ES modules', 'CommonJS']}>
<Tab value="ES modules">

```ts title="imports.mts"
import { createShip, KovalioClient } from "kovalio";
```

</Tab>
<Tab value="CommonJS">

```js title="imports.cjs"
const { KovalioClient } = require("kovalio/client");

```

</Tab>

Imports are passive. An import does not start the CLI, open a database, or create a worker.

## Use the CLI from the same installation

```bash
npx kovalio --help
```

Installing the dependency locally provides both application imports and the command through `npx` or
npm scripts. A global CLI installation does not replace your application's local dependency.

Continue with [remote setup](/docs/api/sdk/client), [native setup](/docs/api/sdk/native), or the
[runnable example](/docs/api/sdk/examples). See [compatibility](/docs/api/sdk/compatibility) for server requirements.
